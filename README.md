# Witch’s Candy Blocks｜女巫糖果工坊

Midnight Candy Club 系列，为 blockblasty.top 制作的独立原创万圣节方块游戏。含经典 8×8 清行玩法，以及五份经过验解的固定魔药订单。当前为完整可玩的静态首版。

## 运行

在本目录运行 `python3 -m http.server 4173`，打开 `http://localhost:4173`。无需构建、CDN、账号或服务器接口。

先选方块，再点其左上角落点；也可直接拖动。键盘 1 / 2 / 3 选方块，方向键调整落点，回车放下，Z 使用每局一次的月光回溯。

## 玩法与创新

- 填满整行或整列消除，交叉格只清除一次；颜色无需匹配。
- 每批三块全部用完才补充；只有所有剩余块都无法摆放时才判定空间耗尽。
- 经典模式每清掉 12 条线酿一瓶魔药，本地保存成绩和未完成局面。
- 魔药订单需要在有限摆放次数内清除带蛛网标记的初始糖果。题面和方块序列固定，五个目标均有经过测试的完整解路。
- 每局一次月光回溯，用于撤销刚才的摆放；得分、棋盘、托盘和随机序列一并还原。
- 原创矢量美术、合成音效、双语、触屏/键盘操作、真实结果分享。

## 验证

`npm test` 使用 Node 内置测试，覆盖越界/占用、多条线交叉清除、托盘补充时机、终局、确定性种子、五份订单完整解路和已结束局面禁操作。

## 文件

`engine.js` 是纯逻辑模块；`app.js` 提供界面、音效、存储与交互；`tests/engine.test.js` 验证真实规则。该作品独立实现，不依赖现有主站 Unity 构建或第三方嵌入。

本地进度不会跨设备同步。分享复制文字与当前订单链接，不上传玩家信息。

## 主站嵌入

游戏会自动识别 iframe 并启用无需页面滚动的紧凑布局；也可用 `?embed=1` 预览。主站窗口尺寸、移动端工具栏留白、权限、订单链接和浏览器验收记录见 [EMBEDDING.md](EMBEDDING.md)。
