# Witch’s Candy Blocks — ハロウィンのお菓子ブロックパズル

🍬 魔女が持ってきたのは、ちょっと変わった形のお菓子。**Witch’s Candy Blocks** は 8×8 の盤面で「次のピースの居場所」を考えるハロウィンパズルです。形をはめ、縦横の列をそろえ、消したお菓子を真夜中の魔法へ変えていきましょう。

## このゲームの楽しみ方

- **8×8 の盤面**と3個ずつのピース。完成した縦横の列を同時に消し、交差するマスは重複して数えません。
- スコアを伸ばす **Classic** と、完全な解法を確認した **5つの Potion Orders**。
- ドラッグ、選択後のタップ、キーボードに対応。置ける位置と、完成する列のプレビューがあります。
- 1回の挑戦で1度だけ使える **Moon Rewind**。直前の盤面、ピース、スコア、目標、乱数の状態まで復元します。
- お菓子、くもの巣、瓶、大釜のオリジナル絵。任意の効果音、動きの削減、ローカル保存にも対応します。

## 基本ルール

トレイから形を選び、空いているマスに全体が収まるように置きます。すでに埋まったマスには重ねられません。縦か横の8マスが全部埋まると、その列が消えます。**色をそろえる必要はなく、ピースの回転もできません。** 落下の制限時間はありません。現在の3個を全部使うと、次の組が届きます。

**Classic** では空きを残しながらスコアを伸ばし、12列消すたびに魔法の瓶が1本完成します。残りのどのピースも置けなくなると終了です。1個だけ置きづらい状態で、直ちに終了するわけではありません。

**Potion Orders** は、最初からくもの巣が付いているお菓子を、指定回数以内の配置で消す問題です。あとから置いたお菓子は新しい目標にはなりません。5問で、1列、対になった列、縦横の交差、3個の配分、2列同時の仕上げを学びます。盤面とピースの順序は固定です。

**Moon Rewind** は1回の挑戦につき1度だけ。空きがなくなった直後でも最後の配置を戻せますが、すでに完成した注文は取り消せません。再挑戦は新しい開始で、無制限の Undo ではありません。

## 操作方法

| 操作 | 入力 |
| --- | --- |
| ピースを選択 | トレイをクリック／タップ、または **1・2・3** |
| ピースを配置 | ドラッグ、または形の左上が来るマスをタップ |
| キーボードで配置 | 矢印で位置を決め、**Enter** で置く |
| Moon Rewind | **Z** または戻すボタン |
| モード・注文・再挑戦・説明 | 画面ボタンや小窓メニュー。キー入力には iframe 内のフォーカスが必要 |

## ちょっとしたコツ

大きな空き地を使う前に、3個すべての形を見てみましょう。目の前の小さな列を消せても、次のピースが入らなくなることがあります。注文では色の付いた全マスではなく、最初のくもの巣を優先します。離す前にプレビューを確認し、Moon Rewind は予想外の結果になった一手のために残しておくと安心です。

## 記録とチャレンジの共有

保存が許可されていれば、Classic の途中盤面、最高スコア、完了した注文、言語と音の設定を残します。端末間同期はありません。[注文3](https://halloween-block-blast.crazy3d.org/#order=3)から固定問題を直接開け、1〜5 の値でほかを選べます。共有は実際のスコアや注文結果とリンクで、リプレイや盤面をサーバーへ送る機能ではありません。コピーできないときは文字を表示します。

## よくある質問

### 3つ並べて消すゲームですか？

形を置いて縦横の列を埋めるゲームです。色は見た目の違いで、隣のお菓子を交換しません。交換型が好きなら、下の Witch’s Potion Match をどうぞ。

### 次のピースが届かないのはなぜ？

現在の3個をすべて使う必要があります。置きやすい形だけでなく、難しい形の場所も先に考えましょう。

### Moon Rewind は何を戻しますか？

直前の盤面、トレイ、スコア、消した列、目標、乱数の状態です。1回の挑戦で1度だけなので、すべての候補を無限に試す機能ではありません。

## ローカルで実行・サイトに埋め込む

リポジトリのルートで HTTP サーバーを起動します。

```sh
python3 -m http.server 4173
```

**http://localhost:4173/** を開いてください。ビルドや依存パッケージは不要です。`file://` では JavaScript モジュールを読み込めない場合があります。

Node で付属のチェックを実行します。

```sh
npm test
```

テストでは無効な配置、縦横の同時消去、トレイ補充、終了状態、決定的な生成、5つの完全解法、Classic の保存検証を確認します。ビルドや依存パッケージの導入は不要です。

```html
<iframe src="https://halloween-block-blast.crazy3d.org/?embed=1"
  title="Witch’s Candy Blocks"
  style="display:block;width:100%;height:654px;border:0"
  allow="fullscreen" allowfullscreen></iframe>
```

デスクトップのゲーム領域は高さ **654 px** です。1160×654、390×650、844×340 のブラウザー枠で、注文の完了と巻き戻しを確認しています。トレイは盤面の横または下に移り、長いダイアログは内部でスクロールできます。

寸法、保存、フォーカス、権限は[埋め込みガイド](EMBEDDING.md)へ。親サイトのツールバーを除いた高さを iframe に割り当ててください。
